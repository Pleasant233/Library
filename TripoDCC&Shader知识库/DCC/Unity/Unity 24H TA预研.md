# 前文
* 本次预研主要验证美术希望实现的光照，材质方案，在引擎实现的可能性。
* 目前有以下需求：
	* 戏剧化的灯光表现
	* 物体表面半写实风格质感
	* 进一步优化的法线描边
	* glitch的全屏特效实现
* 综合预先对于渲染管线的前期调研，最终准备选定6.x新增的Deferred+管线
	* 主要原因有
		* 戏剧性人工光源用光较多，对性能较为敏感，deferred+对点光源选择优化较高，避免了批量的drawcall
		* 只考虑n卡PC平台，对computeShader和GPU驻留（GPU Resident Drawer）等特性支持好
# 需求拆解
## 灯光表现
### 观察
* **欧美复古风质感，印象派，半写实，复古未来主义，暗黑装饰风**。
* 注意到美术在原画氛围表现上，为表现**色块，渐变简约，构成感**，会在软件实现手动的**渐变映射**。
* ![[Pasted image 20260729003602.png]]
* 并且美术明显需要一个能够把控场景整体光照氛围的工具。因此参考[知乎分享](https://zhuanlan.zhihu.com/p/1985730965356704809)，遂准备复现基于距离与法线的自定义Ramp灯光。
### 需求拆解
* 参考知乎文章，对这套流程有以下拆解
	* 1.编辑器层面：提供一套自由调节Ramp灯光渐变范围，颜色，强弱等参数的组件or编辑器面板，能够动态调节场景中指定Ramp灯的表现
	* 2.管线层面：自定义一份lightdata，实现记录光源到物体的距离，采样Ramp图的渐变颜色，实现渐变光照的效果，并与物体法线进行作用。
* 以下是参考文章所需修改的文件部分，由于其为UE的管线，我们需要还原到Unity6.x的URP管线中。

| 文件路径 | 职责 | 修改内容 |
|---|---|---|
| PointLightComponent.h/cpp | 点光源组件，定义灯光属性 | 添加Ramp相关面板属性 |
| SceneManagement.h | 灯光参数结构体，传递给渲染器 | 修改FLightRenderParameters加参数 |
| LightComponent.cpp | 灯光组件基类，构建着色器参数 | 传递Ramp纹理资源到着色器 |
| LightData.ush | Shader端的灯光数据结构 | 修改FDeferredLightData加参数 |
| DeferredLightingCommon.ush | 延迟光照核心Shader代码 | 插入Ramp采样和假GI计算 |
