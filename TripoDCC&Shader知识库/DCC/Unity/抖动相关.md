# 需求与参考
* 美术希望材质在明暗变化时，有波点过度如下图。
* ![[Pasted image 20260804223305.png]]
* 实际上可以看到有多种波点类型，比如排线风格代表阴影的部分，比如半吊的明暗渐变过度的部分。
* 之前参考《奥伯斯丁的回归》完成过基于后处理的抖动实现，当时实现了基于屏幕空间的效果，基本能涵盖美术对于抖动的需求，但问题是屏幕空间会随着相机位置，旋转变化而发生变化，这样的效果是美术不希望的，我们希望这些波点，线条就像印在材质上一样。
* 于是我们开始了一系列尝试
	* 1.世界空间
		* 世界空间方法就是简单的将后处理shader的坐标映射到世界空间中，这样确实解决了一些问题 ![[Pasted image 20260804224954.png|532]]
		* 但也带来了新问题，那就是点阵好像覆盖在物体表面一样，并且由于世界空间缩放是统一的，因此巨大的物体比如地面，其上的波点就相对大，而物件，道具其上的波点就相对小，大小不均匀的现象会使得空间变得更加诡异。不符合我们的预期。
	* 基于uv空间的材质shader
		* 相当于给每个物体分配一个材质，在物体shader初通过运算来进行波点混合，这确实是一种较为简单的方法。但问题就是调试成本太高，每个物体都需要基于符合其面积大小的波点数量，密度等，人力成本过高，如果放在一些小物件上倒是一种解决方案。有待进一步尝试。
